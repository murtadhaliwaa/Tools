# قائمة تسليم النظام للعميل

استخدمها في جلسة التسليم. لا تغنِي عن `docs/ADMIN-AR.md` للتشغيل اليومي.

## قبل التسليم (المورّد)

- [ ] أول مدير يعمل ويستطيع الدخول
- [ ] `NEXT_PUBLIC_SITE_URL` يطابق رابط الإنتاج (لاستعادة كلمة المرور)
- [ ] التسجيل العام مغلق في الإعدادات ما لم يطلب العميل فتحه
- [ ] حسابات أمناء العدة مُنشأة ومُفعّلة (أو تعليم المدير كيف يفعّل)
- [ ] تجربة: تسجيل حركة + تقرير + تصدير
- [ ] نسخة احتياطية حديثة (`npm run db:backup` أو منصة قاعدة البيانات)
- [ ] تسليم رابط الموقع + حساب المدير + رابط **المساعدة** داخل التطبيق

## يوم التسليم — أخبر المدير

1. **تفعيل الحسابات** من قائمة الحسابات إن ظهر «بانتظار موافقة المدير».
2. **الأدوار**: مدير vs أمين عدة — انظر المساعدة أو `ADMIN-AR.md`.
3. **التسجيل العام** من الإعدادات؛ المفضّل إنشاء الحسابات يدوياً.
4. **الحذف في الكتالوج** = إخفاء من القوائم غالباً.
5. **التصدير** محدود الصفوف؛ التقارير ≠ نسخة احتياطية للقاعدة.
6. عند «إعدادات الموقع غير مكتملة» في نسيت كلمة المرور → راجع رابط الموقع مع المورّد.

## بعد التسليم — دعم أقل

- وجّه الأسئلة المتكررة إلى صفحة **المساعدة** داخل التطبيق.
- أعطِ نسخة من `docs/ADMIN-AR.md` (أو PDF مطبوع).
- وثّق جهة الاتصال للطوارئ التقنية فقط (استضافة / قاعدة بيانات / حجب شبكة).

## لا تسلّم للعميل كدليل تشغيل

`README.md` و`docs/SECURITY.md` و`docs/OPS.md` مخصّصة للمطوّر/التشغيل التقني.
